## 2. Why this round exists after a Codex PASS
A re-read of `eb28eb2` found defects in block completeness and critical weeks that the r2 PASS did not cover:
- **Block completeness:** an unregistered extra block was pooled (fixture gave 1733.3 instead of unavailable); a duplicate block record was counted twice; records without a `block_id` were pooled unchecked; block-level records were accepted without a registered block list; completeness was checked over the union of periods, so a block missing in one month was hidden by another.

## 5. Interface changes (eb28eb2 -> da94bf5)
- New `rates.block_problems(observations, required_blocks)`: the single block check used by `pooled_rate`, both baselines and both unusual-label functions.
  - Raises on unregistered or missing `block_id`, duplicate block records in a period, an invalid `required_blocks` value (must be a non-empty tuple of unique strings), or block-tagged records when `required_blocks` is None.
  - Returns per-period reasons when a required block is missing or has no usable observations.
- `compute_critical_weeks(target_year, all_obs, config, cw_config, required_blocks=None) -> CriticalWeeks` replaces `compute_critical_weeks(target_obs, target_year, baseline, top_n=3, ...)`.
- New `CriticalWeekConfig(n_busiest_weeks, ranked_weeks, tie_rule)`: all fields required, no defaults. `tie_rule` is `include_all_tied` or `lower_week_number_first`.
- New `CriticalWeeks` result type: `status`, `critical_weeks`, `ranking`, `cutoff_rate`, `tied_at_cutoff`, `missing_weeks`, `reasons`.
- `label_critical_week(week_number, result)` replaces `label_critical_week(target_obs, target_year, week_number, baseline, top_n=3, ...)`. The label field is now `week_number` (was `calendar_month`); `target_rate`, `threshold_rate` and `tied_with` were removed and `typical_rate` added.
- Removed `compute_weekly_rates` (nothing outside the module used it).
- New package exports: `block_problems`, `CriticalWeekConfig`, `CriticalWeeks`, `CriticalWeekLabel`, `compute_critical_weeks`, `label_critical_week`.
- Unchanged: `label_unusual_week` still handles unusual weeks. The S-NPP cutoff, required baseline years, the conventional median and the nearest-rank p90 are as in r1/r2.
