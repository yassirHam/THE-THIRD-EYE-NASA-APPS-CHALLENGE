## Changes since Round 1 (frontend/ only)

1. **Evidence loading (185937f).** `loadBundle()` keeps `index.entries` and also reads `index.evidence_entries` (`tte-stage-a-evidence-v1`). Each document is fetched and checked against the index sha256. A mismatch, or an unavailable Web Crypto, means the document is not shown. The declared sealed window is shown as sealed, not as missing data.
2. **Release gate.** The CA/BC evidence file says `not_released: P1/P2 claim approval and P5 verification required before public use`. Only the hand-computed Section 4B illustration (8.2/2.8 vs 5.5/5.5) is shown, plus a note that 5 real-data checks are withheld. The real-data panel (`EvidencePanel.tsx`, read by `lab/evidence.ts`) is only built for a released document, so no CA 3218 or BC 826 numbers are public in this round. The reader also refuses the file when `sealed_years_read` is non-empty, and it never shows 2020 or 2021.
3. **Lab workbench (8f63e02).** Map with pan and zoom, single-sensor chart, monthly and weekly heat-map calendar, period detail and state counts. Null values are gaps, never zero. The sealed window is drawn in place, hatched across 2020-2021. The heat-map legend drops empty bins, which fixes the "0 to 0" entry.
4. **Region outlines.** These come from `data/manifests/canonical_regions.geojson` through a build-time `?raw` import, so they are bundled into `dist/` and need no runtime fetch. The map draws only outlines whose geometry ID matches a loaded area. Areas without a supplied boundary are listed but not drawn.
5. **Visuals ported from `p3/frontend`.** Landing, story and professor assets, plus menu music. QuickMission and the 1.3.0 synthetic lab modules were not ported.
