## 2. Interface Finding: Loss of Adverse Partial Footprint Findings

### Finding F-01: `footprint_certification()` maps documented partial footprints to `unverified`
- **File:** `artifact_pipeline/adapters.py` (lines 53–62)
- **Mechanism:**
  In `footprint_certification(geometry_id, p2)`:
  ```python
  if p2.get("certifiable_complete") and evidence == "cell_level" and p2.get("certification_ref") \
          and p2.get("certified_at"):
      return {"geometry_id": geometry_id, "status": "complete", "footprint_evidence": "cell_level",
              "certification_ref": p2["certification_ref"], "certified_at": p2["certified_at"],
              "coverage_fraction": None}
  return {"geometry_id": geometry_id, "status": "unverified", "footprint_evidence": evidence,
          "certification_ref": None, "certified_at": None, "coverage_fraction": None}
  ```
  Any P2 input that is not certified complete automatically defaults to `status: "unverified"` with `coverage_fraction: None`.
- **Scientific Impact:**
  - This collapses documented `partial` footprints into `unverified`, losing an adverse scientific finding.
  - An **unverified** footprint means evidence has not been examined or is unavailable (procedural gap).
  - A **partial** footprint means the footprint was evaluated and documented to be incomplete (adverse finding of fact, e.g. coverage $C < C_{\min}$).
  - Converting documented partial footprints into `unverified` conceals the failure of full spatial coverage and drops the evaluated coverage fraction.
