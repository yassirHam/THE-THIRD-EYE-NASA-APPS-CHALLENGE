# THE THIRD EYE frontend

The browser interface is built with React, TypeScript and Vite.

```sh
npm ci
npm run dev
```

Run `npm run build` for a production build. The application requires the appropriate published artifacts to display measured data; an unavailable or fixture-backed view is not evidence of a completed evaluation. See the [project README](../README.md) and [results summary](../docs/submission/ONE_PAGE_RESULTS.md).
